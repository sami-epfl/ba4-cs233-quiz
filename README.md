# CS-233 — Quiz

**[https://sami-epfl.github.io/ba4-cs233-qcm/](https://sami-epfl.github.io/ba4-cs233-qcm/)**

## Setup

1. Copy `config.example.js` from [ba4-quiz-engine](https://github.com/sami-epfl/ba4-quiz-engine) → `config.js` and fill in your values
2. Open `index.html` in a browser

## Adding a topic

1. Create `topics/my-topic.js` with `registerTopic("Name", ...questions)`
2. Add `<script src="topics/my-topic.js"></script>` in `index.html`
